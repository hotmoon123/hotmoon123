# BiteKasa — starter landing page

A responsive static enquiry page based on the supplied BiteKasa assets and the latest decisions visible in the shared brand discussion. It identifies BiteKasa as a samosa and spring-roll business, explains fried/unfried/frozen product conditions, displays the three advertised packs, links to the revised flyer draft, and gives customers a direct enquiry path.

## Preview locally

From the repository root:

```bash
python -m http.server 8000 --bind 0.0.0.0 --directory bitekasa-site
```

Then open `http://localhost:8000`.

## Offer shown

- **Silver:** GH₵100 · 30 pieces · no drink specified.
- **Golden:** GH₵200 · 50 pieces · 500 ml Coca-Cola.
- **Premium:** GH₵250 · 70 pieces · 1 litre Coca-Cola.

The exact samosa/spring-roll mix and whether the listed prices apply to fried, unfried or frozen products are not established in the flyer. Confirm before accepting an order.

## Before sharing publicly

Verify both telephone numbers, whether the first is WhatsApp-enabled, current prices/stock, package mix, product state, service area, collection/delivery, hours, payment terms, capacity, and any storage/preparation/allergen information. The site does not take payment, check stock, store customer messages, or measure conversions. It makes no delivery, shelf-life, licensing or food-safety guarantee. The phone/WhatsApp integration is provisional until the owner verifies the numbers and account status.
