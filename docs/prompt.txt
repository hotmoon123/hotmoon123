## **“8 ChatGPT Prompt Frameworks To Help You Master AI”**
## **1. R-T-F (Role – Task – Format)**
**R (Role):** Specify the role you want the AI to assume
**T (Task):** Define the task you want AI to perform
**F (Format):** Indicate the output format
**Example:**
* Role → Act as a brand strategist
* Task → Write a messaging hierarchy for a B2B SaaS founder targeting finance teams
* Format → Bullet points with core message, value props, proof, and CTAs
## **2. S-O-L-V-E (Situation – Objective – Limitations – Vision – Execution)**
**S (Situation):** Define the context
**O (Objective):** Specify goals
**L (Limitations):** Define constraints
**V (Vision):** Outline long-term goal
**E (Execution):** Plan steps
**Example:**
* Situation → Leading content team at startup launching product
* Objective → Generate qualified inbound leads
* Limitations → No ad spend, small team
* Vision → Become go-to thought leader
* Execution → Weekly content + double down on best content
## **3. T-A-G (Task – Action – Goal)**
**T (Task):** Define task
**A (Action):** State action needed
**G (Goal):** Clarify desired outcome
**Example:**
* Task → Reduce customer churn
* Action → Analyze churn + retention program
* Goal → Improve retention by 15% in 6 months
## **4. R-A-C-E (Role – Action – Context – Expectation)**
**R (Role):** Character AI plays
**A (Action):** What to do
**C (Context):** Background info
**E (Expectation):** Desired output
**Example:**
* Role → B2B consultant
* Action → Build outreach framework
* Context → Workflow software for logistics firms
* Expectation → 3 templates tailored to buyer roles
## **5. D-R-E-A-M (Define – Research – Execute – Analyse – Measure)**
**D:** Define problem
**R:** Research
**E:** Execute
**A:** Analyse
**M:** Measure
**Example:**
* Define → Declining retention
* Research → CRM + interviews
* Execute → Retention program
* Analyse → Behavior comparison
* Measure → Churn rate, usage, NPS
## **6. P-A-C-T (Problem – Approach – Compromise – Test)**
**P:** Define problem
**A:** Approach
**C:** Trade-offs
**T:** Testing/measurement
**Example:**
* Problem → Low conversion
* Approach → Improve onboarding
* Compromise → Delay feature rollout
* Test → A/B testing
## **7. C-A-R-E (Context – Action – Result – Example)**
**C:** Context
**A:** Action
**R:** Result
**E:** Example
**Example:**
* Context → Low onboarding engagement
* Action → Redesign onboarding
* Result → Higher adoption

## **8. R-I-S-E (Role – Input – Steps – Expectation)**

**I:** Input
**S:** Steps
**E:** Expectation

* Role → Commercial director
* Input → Sales data
* Steps → Identify weak points
* Expectation → Growth strategy

// Single Responsibility: Security Functions

function generateCSRFToken() {
    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}

function validateCSRF($token) {
    return isset($_SESSION['csrf_token']) && hash_equals($_SESSION['csrf_token'], $token);
}

function sanitizeInput($data) {
    return htmlspecialchars(trim($data), ENT_QUOTES, 'UTF-8');
}

function setSecurityHeaders() {
    header("X-Frame-Options: DENY");
    header("X-XSS-Protection: 1; mode=block");
    header("X-Content-Type-Options: nosniff");
    header("Referrer-Policy: strict-origin-when-cross-origin");
}

// Single Responsibility: Reusable Utility Functions

function isValidFile($file) {
    $allowed = ['xlsx', 'xls', 'csv'];
    $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
    $mimeAllowed = ['application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
                    'application/vnd.ms-excel', 'text/csv'];

    return in_array($ext, $allowed) && 
           in_array($file['type'], $mimeAllowed) && 
           $file['size'] <= 5 * 1024 * 1024; // 5MB
}

document.getElementById('uploadForm').addEventListener('submit', async function(e) {
    e.preventDefault();
    
    const fileInput = document.getElementById('file');
    const statusEl = document.getElementById('statusMessage');
    const btn = document.getElementById('submitBtn');

    if (!fileInput.files[0]) {
        alert("Please select a file");
        return;
    }

    btn.disabled = true;
    btn.textContent = "Processing...";
    statusEl.innerHTML = "";

    const formData = new FormData(this);

    try {
        const response = await fetch('actions/process_upload.php', {
            method: 'POST',
            body: formData
        });

        const result = await response.json();

        if (result.status === "success") {
            alert("Upload Successful");
            statusEl.innerHTML = `<span class="text-emerald-600">✓ ${result.imported} records imported successfully</span>`;
            this.reset();
        } else {
            alert("Failed to Upload");
            statusEl.innerHTML = `<span class="text-red-600">✕ ${result.message}</span>`;
        }
    } catch (err) {
        alert("Failed to Upload");
        statusEl.innerHTML = `<span class="text-red-600">✕ Server error occurred</span>`;
    } finally {
        btn.disabled = false;
        btn.textContent = "Upload & Import to Database";
    }
});

require_once '../vendor/autoload.php';

use PhpOffice\PhpSpreadsheet\IOFactory;

header('Content-Type: application/json');
setSecurityHeaders();

$response = ['status' => 'error', 'message' => 'Invalid request'];

// Validate CSRF
if (!isset($_POST['csrf_token']) || !validateCSRF($_POST['csrf_token' reasoning])) {
    $response['message'] = 'Security validation failed';
    echo json_encode($response);
    exit;
}

// Validate File
if (!isset($_FILES['file']) || !isValidFile($_FILES['file'])) {
    $response['message'] = 'Invalid file type or size';
    echo json_encode($response);
    exit;
}

$filePath = $_FILES['file']['tmp_name'];
$ext = strtolower(pathinfo($_FILES['file']['name'], PATHINFO_EXTENSION));
$imported = 0;

try {
    $stmt = $conn->prepare("INSERT IGNORE INTO contacts 
        (first_name, last_name, telephone, address, email) 
        VALUES (?, ?, ?, ?, ?)");

    if ($ext === 'csv') {
        $handle = fopen($filePath, 'r');
        fgetcsv($handle); // skip header
        while (($row = fgetcsv($handle)) !== false) {
            if (count($row) >= 5) {
                $stmt->bind_param("sssss", $row[0], $row[1], $row[2], $row[3], $row[4]);
                if ($stmt->execute()) $imported++;
            }
        }
    } else {
        $spreadsheet = IOFactory::load($filePath);
        $rows = $spreadsheet->getActiveSheet()->toArray(null, true, true, true);
        array_shift($rows); // remove header

        foreach ($rows as $row) {
            if (!empty($row['A']) && !empty($row['E'])) {
                $stmt->bind_param("sssss", $row['A'], $row['B'], $row['C'], $row['D'], $row['E']);
                if ($stmt->execute()) $imported++;
            }
        }
    }

    $response = ['status' => 'success', 'imported' => $imported];
} catch (Exception $e) {
    logError($e->getMessage());
    $response['message'] = 'Processing error. Check logs.';
}

echo json_encode($response);
$conn->close();
?>

## Rent & Lease: The 6 Strict Business Rules

### Rule 1: Financial (Late Fee Auto-Calculation)
```
IF current_date > invoice.due_date
AND invoice.status == "PENDING"
THEN:
    late_fee = base_amount * 0.05 (5%)
    total_due = base_amount + late_fee
    invoice.status = "OVERDUE"
    TRIGGER email alert to Tenant
```

### Rule 2: Financial (Exact Payment Lock)
```
Frontend: Input field is readonly (no editing)
Backend: submitted_amount MUST equal
         (base_amount + late_fee_amount)
IF NOT equal: REJECT with error message
```

### Rule 3: Database (Relational Integrity)
```
IF DELETE property requested
AND active lease EXISTS for property_id
THEN: BLOCK deletion (FK constraint)
SHOW: "Cannot delete leased property"
```

### Rule 4: Logic (Lease Overlap Block)
```
IF CREATE lease requested
AND overlapping dates found for property_id
THEN: REJECT lease creation
SHOW: "Dates overlap with existing lease"
```

### Rule 5: Logic (Ticket Spam Prevention)
```
IF CREATE ticket requested
AND COUNT(active tickets for lease_id) >= 3
THEN: BLOCK ticket creation
SHOW: "Maximum 3 active tickets allowed"
```

### Rule 6: Security (Chat Isolation)
```
IF SEND message requested
AND sender.lease_id != receiver.lease_id
THEN: BLOCK message routing
SHOW: "Unauthorized contact"
```

# 🔐 SECTION 9: COMPLETE SECURITY ARCHITECTURE

## Frontend Security
- Input sanitization before submission
- JavaScript field validation (prevent bad data)
- Readonly fields for locked values
- CSRF token embedded in every form
- No sensitive data stored in localStorage
- Disabled buttons during API calls
  (prevent double-submission attacks)

## Middleware & API Security
- CORS: Whitelist specific frontend domains
- Rate Limiting: 50 requests/minute per IP
- JWT Validation: Every single API request
- IDOR Prevention: Ownership check per ID
  ```
  1. Extract user_id from JWT token
  2. Query: SELECT owner_id FROM resource
     WHERE resource_id = requested_id
  3. IF owner_id != user_id: RETURN 403
  4. ELSE: Process request
  ```

## Backend Security
- No raw SQL string concatenation
- Django ORM or parameterized queries ONLY
- @transaction.atomic on all financial ops
- Sensitive data never in server logs
- Custom 403/404/500 error handlers
- Rate limiter on auth endpoints (5/min)

## Database Security (Row Level Security)
- RLS enabled on sensitive tables
- Policy: Users see ONLY their own records
  ```sql
  ALTER TABLE messages ENABLE ROW LEVEL SECURITY;
  CREATE POLICY isolation_policy ON messages
  FOR SELECT USING (
    sender_id = current_user_id()
    OR receiver_id = current_user_id()
  );
  ```
- Foreign Key constraints enforced
- UNIQUE constraints on email fields
- Passwords: bcrypt hashed (NEVER plain text)
- Backups: Automated daily MySQL dumps

## PHP (Bulk Upload) Security
- CSRF token: bin2hex(random_bytes(32))
- File validation: extension + MIME + size
- Prepared statements: bind_param strictly
- sanitizeInput: htmlspecialchars + trim
- Security headers on EVERY response:
  - X-Frame-Options: DENY
  - X-XSS-Protection: 1; mode=block
  - X-Content-Type-Options: nosniff
  - Referrer-Policy: strict-origin

# 🧠 SECTION 4: BUSINESS RULES & LOGIC

## The 6 Strict Business Rules
These are NON-NEGOTIABLE. Enforced in
the UI, the API, and the Database.

### Rule 1: Late Fee Auto-Calculation
```
TRIGGER: Daily Midnight Cron Job

IF invoice.status == "PENDING"
AND current_date > invoice.due_date
THEN:
  late_fee = base_amount * 0.05
  total_due = base_amount + late_fee
  invoice.status = "OVERDUE"
  TRIGGER email notification to Tenant
```

### Rule 2: Exact Payment Lock
```
FRONTEND:
  Payment amount input = readonly
  Cursor = not-allowed on tap
  Keyboard does NOT open

BACKEND:
  IF submitted_amount != total_due
  THEN: REJECT payment
  RETURN: 400 Bad Request
  MESSAGE: "Must pay exact amount"
```

### Rule 3: Relational Integrity
```
TRIGGER: Landlord clicks Delete Property

BACKEND:
  SELECT COUNT(*) FROM leases
  WHERE property_id = X
  AND status = "ACTIVE"

  IF count > 0:
    BLOCK deletion
    RETURN 409 Conflict
    MESSAGE: "Cannot delete leased property"

DATABASE:
  ON DELETE RESTRICT on leases.property_id FK
```

### Rule 4: Lease Overlap Block
```
TRIGGER: Landlord creates new lease

BACKEND:
  SELECT COUNT(*) FROM leases
  WHERE property_id = X
  AND start_date <= new_end_date
  AND end_date >= new_start_date
  AND status = "ACTIVE"

  IF count > 0:
    REJECT creation
    RETURN 409 Conflict
    MESSAGE: "Dates overlap with active lease"

FRONTEND:
  Debounced check (500ms after date select)
  Input borders turn Muted Red
  Submit button disables
```

### Rule 5: Ticket Spam Prevention
```
TRIGGER: Tenant clicks Submit Ticket

BACKEND:
  SELECT COUNT(*) FROM maintenance_tickets
  WHERE lease_id = X
  AND status != "RESOLVED"

  IF count >= 3:
    BLOCK creation
    RETURN 429 Too Many
    MESSAGE: "Maximum 3 active tickets"

FRONTEND:
  Button turns Light Gray
  Cursor = not-allowed
  Tooltip: "Maximum 3 active requests"
  Shakes on tap attempt
```

### Rule 6: Chat Isolation
```
TRIGGER: User sends a chat message

BACKEND:
  SELECT lease_id FROM leases
  WHERE (tenant_id = sender_id
  OR landlord_id = sender_id)
  AND lease_id = receiver.lease_id

  IF no match found:
    BLOCK message routing
    RETURN 403 Forbidden
    MESSAGE: "Unauthorized contact"

WEBSOCKET:
  Chat rooms named: chat_lease_{lease_id}
  Only lease-matched users join the room
```

## Automated Cron Job Logic

### Job 1: Invoice Generation (Monthly)
```
SCHEDULE: 25th of every month at 00:00

FOR EACH lease WHERE status = "ACTIVE":
  CREATE invoice record:
    lease_id = lease.id
    base_amount = lease.agreed_rent
    late_fee_amount = 0.00
    total_due = agreed_rent
    issue_date = today
    due_date = 1st of next month
    status = "PENDING"

```
SCHEDULE: Every day at 00:01

FOR EACH invoice WHERE status = "PENDING"

## Animation & Motion System

### The Core Formula
```
Movement = State + Trigger + Timing + Rendering
```

### State Changes (What changes)
```
UI States in this system:
  Default → Hover → Active → Disabled
  Loading → Success → Error
  Online → Offline
  Pending → Paid → Overdue
  Collapsed → Expanded
```

### Event Triggers (What causes movement)
```
User Events:
  Click, Tap, Hover, Drag, Scroll,
  Focus, Blur, Type, Submit, Swipe

System Events:
  API Response, WebSocket Message,
  Cron Job Completion, Timer Expiry,
  Page Load, Route Change
```

### Timing Functions (Easing curves)
```
Standard UI transitions:
  0.2s ease-in-out
  (buttons, hovers, small state changes)

Modal/overlay open:
  0.3s cubic-bezier(0.4, 0, 0.2, 1)
  (Material Design standard easing)

Accordion expand:
  0.4s max-height ease
  (smooth content reveal)

Slide-out drawer:
  0.3s cubic-bezier(0.4, 0, 0.2, 1)
  (CRM panel slides in from right)

Physics spring (toggles):
  spring() bounce at end of travel
  (iOS-style toggle switches)
```

### Specific Animations
```
Dashboard revenue number:
  Count up from $0 to final value
  Duration: 1.2s ease-out

Bar/Line charts (Chart.js):
  Bars grow from X-axis upward
  Duration: 1.0s ease-out

Error shake (invalid form):
  Horizontal shake animation
  Duration: 0.4s
  Keyframes: -8px → +8px → -4px → 0

Skeleton loaders (data fetching):
  Pulsing gray blocks
  Duration: 0.8s infinite loop

SVG checkmark (payment success):
  Path draws itself left to right
  Duration: 0.8s ease-in-out

Card hover:
  transform: scale(1.02)
  Duration: 0.2s ease-in-out

Kanban drag:
  transform: rotate(3deg)
  box-shadow: Strong shadow
  (feels "picked up" off canvas)

Scroll reveal (landing page):
  transform: translateY(20px) → 0
  opacity: 0 → 1
  Duration: 0.6s ease-out
  Triggered by IntersectionObserver

Read receipt ticks:
  Color transition from Gray to Blue
  When landlord reads the message
```

### Performance Rules
```
ALWAYS:
  Use CSS transforms (GPU-accelerated)
  Use opacity for show/hide animations
  Use will-change: transform sparingly

NEVER:
  Animate width or height (layout reflow)
  Animate top/left/right/bottom positions
  Use JS animations for simple transitions

SPECIAL RULES:
  500/503 error pages: ZERO animations
  (server is down, save all resources)

  Virtual scrolling for 1000+ list items
  (prevents DOM memory overflow)

  IntersectionObserver for scroll effects
  (better performance than scroll events)

  Debounce API calls minimum 500ms
  (prevents server spam on keypress)
```

# 🔐 SECTION 9: SECURITY ARCHITECTURE

## Frontend Security
```
1. Input sanitization before submission
2. JavaScript field validation (client-side)
3. Readonly inputs for locked values
4. CSRF token in every form submission
5. No sensitive data in localStorage
6. No sensitive data in URL parameters
7. Disabled buttons during processing
   (prevents double-click attacks)
8. Timeout on inactive sessions (30 min)
```

## Middleware Security
```
CORS Policy:
  Whitelist: ['https://rentapp.yourdomain.com']
  Methods: GET, POST, PUT, DELETE, OPTIONS
  Credentials: True (for JWT cookies)
  Reject all other origins → 403

Rate Limiting:
  Standard endpoints: 50 req/min per IP
  Auth endpoints:     5 req/min per IP
  Exceeded → 429 Too Many Requests

JWT Authentication:
  Token stored in HttpOnly cookie
  NEVER in JavaScript localStorage
  Validated on 100% of API requests
  Expiry enforced (rotate on refresh)

IDOR Prevention Logic:
  Step 1: Extract user_id from JWT
  Step 2: Query resource.owner_id
  Step 3: IF user_id != owner_id → 403
  Step 4: ELSE → Process the request
  Applied to: All ID-based API endpoints
```

## Backend Security
```
SQL Queries:
  Django ORM ONLY (no raw strings)
  Parameterized queries where ORM needed
  NEVER concatenate user input into SQL

Financial Operations:
  ALL wrapped in @transaction.atomic
  Rollback on ANY failure mid-transaction
  Prevents money lost in system crashes

Error Handling:
  Custom 400/401/403/404/429/500 handlers
  NEVER expose stack traces to client
  NEVER expose database field names
  Log errors server-side ONLY

Password Storage:
  bcrypt hashing (never plain text)
  Salt rounds: minimum 12
```

## Database Security (Row Level Security)
```
Enable RLS on sensitive tables:

ALTER TABLE chat_messages
  ENABLE ROW LEVEL SECURITY;

CREATE POLICY message_isolation ON chat_messages
  FOR SELECT
  USING (
    sender_id = current_user_id()
    OR receiver_id = current_user_id()
  );

ALTER TABLE leases
  ENABLE ROW LEVEL SECURITY;

CREATE POLICY lease_isolation ON leases
  FOR SELECT
  USING (
    tenant_id = current_user_id()
    OR landlord_id IN (
      SELECT id FROM properties
      WHERE landlord_id = current_user_id()
    )
  );

Additional Database Rules:
  - UNIQUE constraint on users.email
  - ON DELETE RESTRICT on all FK references
  - Passwords: NEVER stored in plain text
  - Backups: Automated daily MySQL dumps
  - Indexes on: lease_id, tenant_id,
    landlord_id, status, created_at
```

<?php
// middleware/AuthMiddleware.php

class AuthMiddleware {
    private $conn;
    private $excludedPaths = [
        '/api/auth/login',
        '/api/auth/register',
        '/api/auth/verify-otp',
        '/api/auth/resend-otp'
    ];
    
    public function __construct($conn) {
        $this->conn = $conn;
    }
    
    public function handle() {
        $requestPath = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
        
        // Skip authentication for excluded paths
        if (in_array($requestPath, $this->excludedPaths)) {
            return true;
        }
        
        // Get token from Authorization header
        $authHeader = $_SERVER['HTTP_AUTHORIZATION'] ?? '';
        
        if (!preg_match('/Bearer\s+(.+)/i', $authHeader, $matches)) {
            $this->sendUnauthorized('Authentication required');
            return false;
        }
        
        $token = $matches[1];
        
        // Verify JWT
        $payload = JWT::verify($token);
        
        if (!$payload) {
            $this->sendUnauthorized('Invalid or expired token');
            return false;
        }
        
        // Check if user still exists and is verified
        $stmt = $this->conn->prepare("
            SELECT id, username, email, role, is_verified 
            FROM users 
            WHERE id = ?
        ");
        $stmt->bind_param("i", $payload['user_id']);
        $stmt->execute();
        $user = $stmt->get_result()->fetch_assoc();
        
        if (!$user) {
            $this->sendUnauthorized('User not found');
            return false;
        }
        
        if (!$user['is_verified']) {
            $this->sendUnauthorized('Account not verified');
            return false;
        }
        
        // Store user in global context
        $GLOBALS['authenticated_user'] = $user;
        
        // Log access
        $this->logAccess($user['id'], $requestPath);
        
        return true;
    }
    
    private function sendUnauthorized($message) {
        http_response_code(401);
        header('Content-Type: application/json');
        echo json_encode([
            'status' => 'error',
            'message' => $message
        ]);
        exit;
    }
    
    private function logAccess($userId, $path) {
        $stmt = $this->conn->prepare("
            INSERT INTO audit_logs (user_id, action, resource_type, ip_address, user_agent, status)
            VALUES (?, 'api_access', 'endpoint', ?, ?, 'success')
        ");
        $ip = $_SERVER['REMOTE_ADDR'];
        $userAgent = $_SERVER['HTTP_USER_AGENT'] ?? 'Unknown';
        $stmt->bind_param("iss", $userId, $ip, $userAgent);
        $stmt->execute();
    }
}

// Helper function to get authenticated user
function getAuthenticatedUser() {
    return $GLOBALS['authenticated_user'] ?? null;
}

function requireAuth() {
    if (!isset($GLOBALS['authenticated_user'])) {
        http_response_code(401);
        echo json_encode(['error' => 'Authentication required']);
        exit;
    }
    return $GLOBALS['authenticated_user'];
}

### 6.2.3 Rate Limiting Middleware

```php
<?php
// middleware/RateLimitMiddleware.php

class RateLimitMiddleware {
    private $conn;
    
    // Rate limit configurations
    private $limits = [
        'default' => ['max' => 60, 'window' => 60],      // 60 req/min
        'auth' => ['max' => 5, 'window' => 300],         // 5 req/5min
        'otp' => ['max' => 3, 'window' => 600],          // 3 req/10min
        'search' => ['max' => 30, 'window' => 60],       // 30 req/min
        'upload' => ['max' => 10, 'window' => 3600]      // 10 req/hour
    ];
    
    public function __construct($conn) {
        $this->conn = $conn;
    }
    
    public function handle($limitType = 'default') {
        $identifier = $this->getIdentifier();
        $config = $this->limits[$limitType] ?? $this->limits['default'];
        
        $result = $this->checkLimit($identifier, $limitType, $config);
        
        // Set rate limit headers
        header("X-RateLimit-Limit: {$config['max']}");
        header("X-RateLimit-Remaining: {$result['remaining']}");
        header("X-RateLimit-Reset: {$result['reset']}");
        
        if (!$result['allowed']) {
            header("Retry-After: {$config['window']}");
            http_response_code(429);
            header('Content-Type: application/json');
            echo json_encode([
                'status' => 'error',
                'message' => $result['message'],
                'retry_after' => $config['window']
            ]);
            exit;
        }
        
        return true;
    }
    
    private function getIdentifier() {
        // Use authenticated user ID if available, otherwise IP
        if (isset($GLOBALS['authenticated_user'])) {
            return 'user_' . $GLOBALS['authenticated_user']['id'];
        }
        return 'ip_' . $_SERVER['REMOTE_ADDR'];
    }
    
    private function checkLimit($identifier, $action, $config) {
        // Clean up old entries
        $this->cleanup($config['window']);
        
        // Get current count
        $stmt = $this->conn->prepare("
            SELECT COUNT(*) as count
            FROM rate_limits
            WHERE identifier = ? 
            AND action_type = ?
            AND window_start > DATE_SUB(NOW(), INTERVAL ? SECOND)
        ");
        $stmt->bind_param("ssi", $identifier, $action, $config['window']);
        $stmt->execute();
        $result = $stmt->get_result()->fetch_assoc();
        
        $count = (int)$result['count'];
        $remaining = max(0, $config['max'] - $count - 1);
        $resetTime = time() + $config['window'];
        
        if ($count >= $config['max']) {
            return [
                'allowed' => false,
                'remaining' => 0,
                'reset' => $resetTime,
                'message' => "Rate limit exceeded. Try again in " . 
                            ceil($config['window'] / 60) . " minutes."
            ];
        }
        
        // Log this request
        $stmt = $this->conn->prepare("
            INSERT INTO rate_limits (identifier, action_type, window_start)
            VALUES (?, ?, NOW())
        ");
        $stmt->bind_param("ss", $identifier, $action);
        $stmt->execute();
        
        return [
            'allowed' => true,
            'remaining' => $remaining,
            'reset' => $resetTime
        ];
    }
    
    private function cleanup($windowSeconds) {
        // Only run cleanup 10% of the time to reduce overhead
        if (rand(1, 10) !== 1) {
            return;
        }
        
        $stmt = $this->conn->prepare("
            DELETE FROM rate_limits 
            WHERE window_start < DATE_SUB(NOW(), INTERVAL ? SECOND)
        ");
        $stmt->bind_param("i", $windowSeconds);
        $stmt->execute();
    }
}
?>

<?php
// middleware/ValidationMiddleware.php

class ValidationMiddleware {
    private $errors = [];
    
    public function validate($rules) {
        $data = $this->parseInput();
        
        foreach ($rules as $field => $fieldRules) {
            $value = $data[$field] ?? null;
            
            foreach ($fieldRules as $rule => $ruleValue) {
                if (!$this->applyRule($field, $value, $rule, $ruleValue)) {
                    break; // Stop on first error
                }
            }
        }
        
        if (!empty($this->errors)) {
            http_response_code(400);
            header('Content-Type: application/json');
            echo json_encode([
                'status' => 'error',
                'message' => 'Validation failed',
                'errors' => $this->errors
            ]);
            exit;
        }
        
        return $this->sanitizeData($data);
    }
    
    private function parseInput() {
        $contentType = $_SERVER['CONTENT_TYPE'] ?? '';
        
        if (strpos($contentType, 'application/json') !== false) {
            $rawInput = file_get_contents('php://input');
            $data = json_decode($rawInput, true);
            
            if (json_last_error() !== JSON_ERROR_NONE) {
                http_response_code(400);
                echo json_encode(['error' => 'Invalid JSON']);
                exit;
            }
            
            return $data;
        }
        
        return $_POST;
    }
    
    private function applyRule($field, $value, $rule, $ruleValue) {
        switch ($rule) {
            case 'required':
                if ($ruleValue && (is_null($value) || trim($value) === '')) {
                    $this->errors[$field] = ucfirst(str_replace('_', ' ', $field)) . ' is required';
                    return false;
                }
                break;
                
            case 'email':
                if ($ruleValue && !filter_var($value, FILTER_VALIDATE_EMAIL)) {
                    $this->errors[$field] = 'Invalid email format';
                    return false;
                }
                break;
                
            case 'phone':
                if ($ruleValue && !$this->validateGhanaPhone($value)) {
                    $this->errors[$field] = 'Invalid Ghana phone number';
                    return false;
                }
                break;
                
            case 'min':
                if (is_numeric($value) && $value < $ruleValue) {
                    $this->errors[$field] = "Must be at least $ruleValue";
                    return false;
                }
                break;
                
            case 'max':
                if (is_numeric($value) && $value > $ruleValue) {
                    $this->errors[$field] = "Must be no more than $ruleValue";
                    return false;
                }
                break;
                
            case 'minLength':
                if (strlen($value) < $ruleValue) {
                    $this->errors[$field] = "Must be at least $ruleValue characters";
                    return false;
                }
                break;
                
            case 'maxLength':
                if (strlen($value) > $ruleValue) {
                    $this->errors[$field] = "Cannot exceed $ruleValue characters";
                    return false;
                }
                break;
                
            case 'pattern':
                if (!preg_match($ruleValue, $value)) {
                    $this->errors[$field] = 'Invalid format';
                    return false;
                }
                break;
                
            case 'in':
                if (!in_array($value, $ruleValue)) {
                    $this->errors[$field] = 'Invalid value';
                    return false;
                }
                break;
                
            case 'numeric':
                if ($ruleValue && !is_numeric($value)) {
                    $this->errors[$field] = 'Must be a number';
                    return false;
                }
                break;
                
            case 'integer':
                if ($ruleValue && !filter_var($value, FILTER_VALIDATE_INT)) {
                    $this->errors[$field] = 'Must be an integer';
                    return false;
                }
                break;
                
            case 'url':
                if ($ruleValue && !filter_var($value, FILTER_VALIDATE_URL)) {
                    $this->errors[$field] = 'Invalid URL format';
                    return false;
                }
                break;
                
            case 'date':
                if ($ruleValue && !$this->validateDate($value)) {
                    $this->errors[$field] = 'Invalid date format';
                    return false;
                }
                break;
                
            case 'unique':
                if ($ruleValue && !$this->checkUnique($field, $value, $ruleValue)) {
                    $this->errors[$field] = 'Already exists';
                    return false;
                }
                break;
                
            case 'exists':
                if ($ruleValue && !$this->checkExists($field, $value, $ruleValue)) {
                    $this->errors[$field] = 'Not found';
                    return false;
                }
                break;
        }
        
        return true;
    }
    
    private function validateGhanaPhone($phone) {
        $cleaned = preg_replace('/\D/', '', $phone);
        
        if (strlen($cleaned) !== 10 || $cleaned[0] !== '0') {
            return false;
        }
        
        $validPrefixes = ['024','025','053','054','055','059',
                          '020','050',
                          '027','057','026','056'];
        
        $prefix = substr($cleaned, 0, 3);
        return in_array($prefix, $validPrefixes);
    }
    
    private function validateDate($date) {
        $d = DateTime::createFromFormat('Y-m-d', $date);
        return $d && $d->format('Y-m-d') === $date;
    }
    
    private function checkUnique($field, $value, $config) {
        global $conn;
        
        $table = $config['table'];
        $column = $config['column'] ?? $field;
        $except = $config['except'] ?? null;
        
        $sql = "SELECT 1 FROM $table WHERE $column = ?";
        $params = [$value];
        $types = 's';
        
        if ($except) {
            $sql .= " AND id != ?";
            $params[] = $except;
            $types .= 'i';
        }
        
        $stmt = $conn->prepare($sql);
        $stmt->bind_param($types, ...$params);
        $stmt->execute();
        $stmt->store_result();
        
        return $stmt->num_rows === 0;
    }
    
    private function checkExists($field, $value, $config) {
        global $conn;
        
        $table = $config['table'];
        $column = $config['column'] ?? $field;
        
        $stmt = $conn->prepare("SELECT 1 FROM $table WHERE $column = ?");
        $stmt->bind_param('s', $value);
        $stmt->execute();
        $stmt->store_result();
        
        return $stmt->num_rows > 0;
    }
    
    private function sanitizeData($data) {
        $sanitized = [];
        
        foreach ($data as $key => $value) {
            if (is_string($value)) {
                $value = trim($value);
                $value = htmlspecialchars($value, ENT_QUOTES, 'UTF-8');
            }
            $sanitized[$key] = $value;
        }
        
        return $sanitized;
    }
}

### 6.2.5 CSRF Protection Middleware

```php
<?php
// middleware/CSRFMiddleware.php

class CSRFMiddleware {
    private $excludedMethods = ['GET', 'HEAD', 'OPTIONS'];
    
    public function handle() {
        // Skip CSRF for safe methods
        if (in_array($_SERVER['REQUEST_METHOD'], $this->excludedMethods)) {
            return true;
        }
        
        // Get token from request
        $token = $this->getTokenFromRequest();
        
        if (!$token) {
            $this->sendForbidden('CSRF token missing');
            return false;
        }
        
        // Verify token
        if (!$this->verifyToken($token)) {
            $this->sendForbidden('Invalid CSRF token');
            return false;
        }
        
        return true;
    }
    
    private function getTokenFromRequest() {
        // Check header first
        if (isset($_SERVER['HTTP_X_CSRF_TOKEN'])) {
            return $_SERVER['HTTP_X_CSRF_TOKEN'];
        }
        
        // Check POST body
        if (isset($_POST['csrf_token'])) {
            return $_POST['csrf_token'];
        }
        
        // Check JSON body
        $rawInput = file_get_contents('php://input');
        $data = json_decode($rawInput, true);
        
        return $data['csrf_token'] ?? null;
    }
    
    private function verifyToken($token) {
        session_start();
        
        if (!isset($_SESSION['csrf_token'])) {
            return false;
        }
        
        return hash_equals($_SESSION['csrf_token'], $token);
    }
    
    private function sendForbidden($message) {
        http_response_code(403);
        header('Content-Type: application/json');
        echo json_encode([
            'status' => 'error',
            'message' => $message
        ]);
        exit;
    }
    
    public static function generateToken() {
        session_start();
        
        if (empty($_SESSION['csrf_token'])) {
            $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
        }
        
        return $_SESSION['csrf_token'];
    }
}
?>

<?php
// middleware/LoggingMiddleware.php

class LoggingMiddleware {
    private $conn;
    private $startTime;
    
    public function __construct($conn) {
        $this->conn = $conn;
        $this->startTime = microtime(true);
    }
    
    public function logRequest() {
        $this->log('request', [
            'method' => $_SERVER['REQUEST_METHOD'],
            'uri' => $_SERVER['REQUEST_URI'],
            'ip' => $_SERVER['REMOTE_ADDR'],
            'user_agent' => $_SERVER['HTTP_USER_AGENT'] ?? 'Unknown',
            'user_id' => $GLOBALS['authenticated_user']['id'] ?? null
        ]);
    }

        $duration = (microtime(true) - $this->startTime) * 1000; // ms
        
        $this->log('response', [
            'status_code' => $statusCode,
            'duration_ms' => round($duration, 2),
            'response_size' => $responseSize,
            'memory_peak' => memory_get_peak_usage(true)
        ]);
    }
    
    public function logError($exception) {
        $this->log('error', [
            'message' => $exception->getMessage(),
            'file' => $exception->getFile(),
            'line' => $exception->getLine(),
            'trace' => $exception->getTraceAsString()
        ], 'error');
    }
    
    private function log($type, $data, $level = 'info') {
        // Database logging
        $stmt = $this->conn->prepare("

class ResponseMiddleware {
    private $startTime;

        ];

    public function formatError($message, $statusCode = 400, $errors = null) {
        $response = [
            'status' => 'error',
            'message' => $message,
            'meta' => $this->getMeta()
        ];
        
        if ($errors) {
            $response['errors'] = $errors;
        }
        
        $this->send($response, $statusCode);
    }
    
    public function formatPaginated($data, $pagination) {
        $response = [
            'status' => 'success',
            'data' => $data,
            'pagination' => [
                'page' => (int)$pagination['page'],
                'limit' => (int)$pagination['limit'],
                'total' => (int)$pagination['total'],
                'pages' => (int)ceil($pagination['total'] / $pagination['limit'])
            ],
            'meta' => $this->getMeta()
        ];
        
        $this->send($response);
    }
    
    private function getMeta() {
        $duration = (microtime(true) - $this->startTime) * 1000;
        
        return [
            'timestamp' => time(),
            'duration_ms' => round($duration, 2),
            'version' => '1.0'
        ];
    }

        http_response_code($statusCode);
        header('Content-Type: application/json; charset=UTF-8');
        header('X-Content-Type-Options: nosniff');
        
        $json = json_encode($response, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
        
        // Log response size
        $responseSize = strlen($json);
        header("X-Response-Size: $responseSize");
        
        echo $json;
        exit;
    }
}

## 6.3 Middleware Pipeline Implementation

```php
<?php
// middleware/MiddlewarePipeline.php

class MiddlewarePipeline {
    private $middlewares = [];
    private $conn;
    
    public function __construct($conn) {
        $this->conn = $conn;
    }
    
    public function add($middleware) {
        $this->middlewares[] = $middleware;
        return $this;
    }
    
    public function execute() {
        foreach ($this->middlewares as $middleware) {
            if (is_callable($middleware)) {
                $result = $middleware();
            } elseif (is_string($middleware)) {
                $instance = new $middleware($this->conn);
                $result = $instance->handle();
            } elseif (is_object($middleware)) {
                $result = $middleware->handle();
            }
            
            // If middleware returns false, stop execution
            if ($result === false) {
                return false;
            }
        }
        
        return true;
    }
}

    private static $cipher = 'aes-256-gcm';
    
    public static function encrypt($plaintext) {
        $key = base64_decode(getenv('ENCRYPTION_KEY'));
        $iv = random_bytes(openssl_cipher_iv_length(self::$cipher));
        $tag = '';
        
        $ciphertext = openssl_encrypt(
            $plaintext,
            self::$cipher,
            $key,
            OPENSSL_RAW_DATA,
            $iv,
            $tag
        );
        
        // Return: IV + tag + ciphertext (all base64)
        return base64_encode($iv . $tag . $ciphertext);
    }

        $data = base64_decode($encrypted);

        $iv = substr($data, 0, $ivLen);
        $tag = substr($data, $ivLen, 16);
        $ciphertext = substr($data, $ivLen + 16);
        
        return openssl_decrypt(
            $ciphertext,
            self::$cipher,
            $key,
            OPENSSL_RAW_DATA,
            $iv,
            $tag
        );
    }
}

### 7.1.4 A04:2021 – Insecure Design

**What it is:**
Flaws in the design/architecture, not implementation bugs.

**Example: Weak OTP System**

```php
<?php
// ❌ BAD DESIGN: Predictable OTP
function generateWeakOTP() {
    return rand(1000, 9999); // Predictable!
}

// ✅ GOOD DESIGN: Cryptographically secure
function generateSecureOTP() {
    return str_pad(random_int(0, 9999), 4, '0', STR_PAD_LEFT);
}

// ❌ BAD DESIGN: No expiry
function storeOTP_Bad($conn, $phone, $otp) {
    $stmt = $conn->prepare("INSERT INTO otps (phone, otp) VALUES (?, ?)");

    $stmt->execute();

// ✅ GOOD DESIGN: Expiry + attempt limit + hashing
function storeOTP_Good($conn, $userId, $phone, $otp) {
    // Invalidate old OTPs
    $conn->query("UPDATE otp_verification SET is_used = 1 WHERE phone = '$phone'");
    
    // Store hashed OTP with expiry
    $otpHash = password_hash($otp, PASSWORD_BCRYPT);
    $expiresAt = date('Y-m-d H:i:s', time() + 120); // 2 minutes
    
    $stmt = $conn->prepare("
        INSERT INTO otp_verification 
        (user_id, phone, otp_hash, expires_at, attempts)
        VALUES (?, ?, ?, ?, 0)
    ");
    $stmt->bind_param("isss", $userId, $phone, $otpHash, $expiresAt);

// ✅ GOOD DESIGN: Secure verification
function verifyOTP_Good($conn, $phone, $inputOTP) {
    $stmt = $conn->prepare("
        SELECT id, otp_hash, attempts, expires_at
        FROM otp_verification
        WHERE phone = ? AND is_used = 0
        ORDER BY created_at DESC
        LIMIT 1
    ");
    $stmt->bind_param("s", $phone);
    $stmt->execute();
    $result = $stmt->get_result()->fetch_assoc();
    
    if (!$result) {
        return ['valid' => false, 'error' => 'No OTP found'];
    }
    
    // Check expiry
    if (strtotime($result['expires_at']) < time()) {
        return ['valid' => false, 'error' => 'OTP expired'];
    }
    
    // Check attempts
    if ($result['attempts'] >= 3) {
        return ['valid' => false, 'error' => 'Too many attempts'];
    }
    
    // Increment attempts
    $conn->query("UPDATE otp_verification SET attempts = attempts + 1 WHERE id = {$result['id']}");
    
    // Verify hash
    if (password_verify($inputOTP, $result['otp_hash'])) {

            $logFile = __DIR__ . '/../logs/security_' . date('Y-m-d') . '.log';
            $entry = sprintf(
                "[%s] %s.%s (%s): %s\n",
                date('Y-m-d H:i:s'),
                $category,
                $event,
                $level,
                $dataJson
            );
            file_put_contents($logFile, $entry, FILE_APPEND | LOCK_EX);
        }
    }
    
    private function sendAlert($event, $details) {
        // Send email/SMS/Slack notification
        $message = "SECURITY ALERT: $event\n" . json_encode($details);
        error_log($message);
        // mail('admin@yourapp.com', 'Security Alert', $message);
    }
}

// Usage examples

// Login attempt

// Failed authorization

// Suspicious pattern detection

    $logger->logSuspicious('brute_force_attempt', 'critical', [

    ]);

## 7.2 Input Sanitization Comprehensive Guide

```php
<?php
// Complete input sanitization functions

class InputSanitizer {
    /**
     * Sanitize string (remove HTML, trim, normalize)
     */
    public static function sanitizeString($input) {
        if (!is_string($input)) {
            return '';
        }
        
        // Remove null bytes
        $input = str_replace("\0", '', $input);
        
        // Trim whitespace
        $input = trim($input);
        
        // Strip HTML tags
        $input = strip_tags($input);
        
        // Convert special characters to HTML entities
        $input = htmlspecialchars($input, ENT_QUOTES | ENT_HTML5, 'UTF-8');
        
        return $input;
    }
    
    /**
     * Sanitize email
     */
    public static function sanitizeEmail($email) {
        $email = filter_var($email, FILTER_SANITIZE_EMAIL);
        $email = strtolower(trim($email));
        
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            return false;
        }
        
        return $email;
    }
    
    /**
     * Sanitize phone number (Ghana)
     */
    public static function sanitizePhone($phone) {
        // Remove all non-digits
        $phone = preg_replace('/\D/', '', $phone);
        
        // Remove leading zeros from country code
        if (strpos($phone, '233') === 0) {
            $phone = '0' . substr($phone, 3);
        }
        
        // Must be 10 digits starting with 0
        if (strlen($phone) !== 10 || $phone[0] !== '0') {
            return false;
        }
        
        return $phone;
    }
    
    /**
     * Sanitize integer
     */
    public static function sanitizeInt($input, $min = null, $max = null) {
        $value = filter_var($input, FILTER_VALIDATE_INT);
        
        if ($value === false) {
            return false;
        }
        
        if ($min !== null && $value < $min) {
            return false;
        }
        
        if ($max !== null && $value > $max) {
            return false;
        }
        
        return $value;
    }
    
    /**
     * Sanitize float/decimal
     */
    public static function sanitizeFloat($input, $min = null, $max = null, $decimals = 2) {
        $value = filter_var($input, FILTER_VALIDATE_FLOAT);
        
        if ($value === false) {
            return false;
        }
        
        $value = round($value, $decimals);
        
        if ($min !== null && $value < $min) {
            return false;
        }
        
        if ($max !== null && $value > $max) {
            return false;
        }
        
        return $value;
    }
    
    /**
     * Sanitize URL
     */
    public static function sanitizeUrl($url) {
        $url = filter_var($url, FILTER_SANITIZE_URL);
        
        if (!filter_var($url, FILTER_VALIDATE_URL)) {
            return false;
        }
        
        // Only allow HTTPS
        if (strpos($url, 'https://') !== 0) {
            return false;
        }
        
        return $url;
    }
    
    /**
     * Sanitize filename
     */
    public static function sanitizeFilename($filename) {
        // Remove path information
        $filename = basename($filename);
        
        // Remove special characters except dots, hyphens, underscores
        $filename = preg_replace('/[^a-zA-Z0-9._-]/', '', $filename);
        
        // Prevent directory traversal
        $filename = str_replace(['..', '//', '\\'], '', $filename);
        
        // Limit length
        if (strlen($filename) > 255) {
            $filename = substr($filename, 0, 255);
        }
        
        return $filename;
    }
    
    /**
     * Sanitize array (recursive)
     */
    public static function sanitizeArray($array) {
        $sanitized = [];
        
        foreach ($array as $key => $value) {
            $cleanKey = self::sanitizeString($key);
            
            if (is_array($value)) {
                $sanitized[$cleanKey] = self::sanitizeArray($value);
            } else {
                $sanitized[$cleanKey] = self::sanitizeString($value);
            }
        }
        
        return $sanitized;
    }
    
    /**
     * Sanitize JSON
     */
    public static function sanitizeJson($json) {
        $data = json_decode($json, true);
        
        if (json_last_error() !== JSON_ERROR_NONE) {
            return false;
        }
        
        return self::sanitizeArray($data);
    }
    
    /**
     * Sanitize SQL LIKE pattern
     */
    public static function sanitizeLikePattern($input) {
        // Escape special LIKE characters
        $input = str_replace(['%', '_'], ['\%', '\_'], $input);
        $input = self::sanitizeString($input);
        
        return $input;
    }
    
    /**
     * Remove XSS attempts
     */
    public static function removeXSS($input) {
        // Remove any null bytes
        $input = str_replace("\0", '', $input);
        
        // Remove script tags
        $input = preg_replace('/<script\b[^>]*>(.*?)<\/script>/is', '', $input);
        
        // Remove event handlers
        $input = preg_replace('/\bon\w+\s*=\s*["\']?[^"\']*["\']?/i', '', $input);
        
        // Remove javascript: protocol
        $input = preg_replace('/javascript:/i', '', $input);
        
        // Remove data: protocol
        $input = preg_replace('/data:/i', '', $input);
        
        return $input;
    }
}

// Usage examples

$name = InputSanitizer::sanitizeString($_POST['name']);
$email = InputSanitizer::sanitizeEmail($_POST['email']);
$phone = InputSanitizer::sanitizePhone($_POST['phone']);
$age = InputSanitizer::sanitizeInt($_POST['age'], 18, 120);
$score = InputSanitizer::sanitizeFloat($_POST['score'], 0, 100, 2);
$website = InputSanitizer::sanitizeUrl($_POST['website']);

class QueryCache {
    private $redis;
    
    public function __construct() {
        $this->redis = new Redis();
        $this->redis->connect('127.0.0.1', 6379);
    }

        if ($cached !== false) {

// RULE 1: Debounce expensive operations
function debounce(func, wait) {
    let timeout;
    return function executedFunction(...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, args), wait);
    };
}

// Usage: Search input
const searchInput = document.getElementById('search');
const performSearch = debounce(function(query) {
    // Expensive search operation
    fetch(`/api/search?q=${query}`)
        .then(res => res.json())
        .then(data => displayResults(data));
}, 300);

searchInput.addEventListener('input', e => performSearch(e.target.value));


// RULE 2: Throttle scroll/resize events
function throttle(func, limit) {
    let inThrottle;
    return function(...args) {
        if (!inThrottle) {
            func.apply(this, args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

    $stmt = $conn->prepare("
        SELECT id, otp_hash, attempts, expires_at
        FROM otp_verification
        WHERE phone = ? AND is_used = 0
        ORDER BY created_at DESC
        LIMIT 1
    ");

        return ['valid' => false, 'error' => 'No OTP found'];

// Complete input sanitization functions

class InputSanitizer {
    /**
     * Sanitize string (remove HTML, trim, normalize)
     */
    public static function sanitizeString($input) {
        if (!is_string($input)) {
            return '';
        }
        
        // Remove null bytes
        $input = str_replace("\0", '', $input);
        
        // Trim whitespace
        $input = trim($input);
        
        // Strip HTML tags
        $input = strip_tags($input);
        
        // Convert special characters to HTML entities
        $input = htmlspecialchars($input, ENT_QUOTES | ENT_HTML5, 'UTF-8');
        
        return $input;
    }
    
    /**
     * Sanitize email
     */
    public static function sanitizeEmail($email) {
        $email = filter_var($email, FILTER_SANITIZE_EMAIL);
        $email = strtolower(trim($email));
        
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            return false;
        }
        
        return $email;
    }
    
    /**
     * Sanitize phone number (Ghana)
     */
    public static function sanitizePhone($phone) {
        // Remove all non-digits
        $phone = preg_replace('/\D/', '', $phone);
        
        // Remove leading zeros from country code
        if (strpos($phone, '233') === 0) {
            $phone = '0' . substr($phone, 3);
        }
        
        // Must be 10 digits starting with 0
        if (strlen($phone) !== 10 || $phone[0] !== '0') {
            return false;
        }
        
        return $phone;
    }
    
    /**
     * Sanitize integer
     */
    public static function sanitizeInt($input, $min = null, $max = null) {
        $value = filter_var($input, FILTER_VALIDATE_INT);
        
        if ($value === false) {
            return false;
        }
        
        if ($min !== null && $value < $min) {
            return false;
        }
        
        if ($max !== null && $value > $max) {
            return false;
        }
        
        return $value;
    }
    
    /**
     * Sanitize float/decimal
     */
    public static function sanitizeFloat($input, $min = null, $max = null, $decimals = 2) {
        $value = filter_var($input, FILTER_VALIDATE_FLOAT);
        
        if ($value === false) {
            return false;
        }
        
        $value = round($value, $decimals);
        
        if ($min !== null && $value < $min) {
            return false;
        }
        
        if ($max !== null && $value > $max) {
            return false;
        }
        
        return $value;
    }
    
    /**
     * Sanitize URL
     */
    public static function sanitizeUrl($url) {
        $url = filter_var($url, FILTER_SANITIZE_URL);
        
        if (!filter_var($url, FILTER_VALIDATE_URL)) {
            return false;
        }
        
        // Only allow HTTPS
        if (strpos($url, 'https://') !== 0) {
            return false;
        }
        
        return $url;
    }
    
    /**
     * Sanitize filename
     */
    public static function sanitizeFilename($filename) {
        // Remove path information
        $filename = basename($filename);
        
        // Remove special characters except dots, hyphens, underscores
        $filename = preg_replace('/[^a-zA-Z0-9._-]/', '', $filename);
        
        // Prevent directory traversal
        $filename = str_replace(['..', '//', '\\'], '', $filename);
        
        // Limit length
        if (strlen($filename) > 255) {
            $filename = substr($filename, 0, 255);
        }
        
        return $filename;
    }
    
    /**
     * Sanitize array (recursive)
     */
    public static function sanitizeArray($array) {
        $sanitized = [];
        
        foreach ($array as $key => $value) {
            $cleanKey = self::sanitizeString($key);
            
            if (is_array($value)) {
                $sanitized[$cleanKey] = self::sanitizeArray($value);
            } else {
                $sanitized[$cleanKey] = self::sanitizeString($value);
            }
        }
        
        return $sanitized;
    }
    
    /**
     * Sanitize JSON
     */
    public static function sanitizeJson($json) {
        $data = json_decode($json, true);
        
        if (json_last_error() !== JSON_ERROR_NONE) {
            return false;
        }
        
        return self::sanitizeArray($data);
    }
    
    /**
     * Sanitize SQL LIKE pattern
     */
    public static function sanitizeLikePattern($input) {
        // Escape special LIKE characters
        $input = str_replace(['%', '_'], ['\%', '\_'], $input);
        $input = self::sanitizeString($input);
        
        return $input;
    }
    
    /**
     * Remove XSS attempts
     */
    public static function removeXSS($input) {
        // Remove any null bytes
        $input = str_replace("\0", '', $input);
        
        // Remove script tags
        $input = preg_replace('/<script\b[^>]*>(.*?)<\/script>/is', '', $input);
        
        // Remove event handlers
        $input = preg_replace('/\bon\w+\s*=\s*["\']?[^"\']*["\']?/i', '', $input);
        
        // Remove javascript: protocol
        $input = preg_replace('/javascript:/i', '', $input);
        
        // Remove data: protocol
        $input = preg_replace('/data:/i', '', $input);
        
        return $input;
    }
}

$email = InputSanitizer::sanitizeEmail($_POST['email']);

        $this->redis->connect('127.0.0.1', 6379);

        if ($cached !== false) {

// RULE 1: Debounce expensive operations
function debounce(func, wait) {
    let timeout;
    return function executedFunction(...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, args), wait);
    };
}

// Usage: Search input
const searchInput = document.getElementById('search');
const performSearch = debounce(function(query) {
    // Expensive search operation
    fetch(`/api/search?q=${query}`)
        .then(res => res.json())
        .then(data => displayResults(data));
}, 300);

searchInput.addEventListener('input', e => performSearch(e.target.value));


// RULE 2: Throttle scroll/resize events
function throttle(func, limit) {
    let inThrottle;
    return function(...args) {
        if (!inThrottle) {
            func.apply(this, args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

// Usage: Scroll event
window.addEventListener('scroll', throttle(function() {
    console.log('Scrolled!');
}, 100));

        $message = $exception->getMessage();

        $statusCode = 500;
        $message = "An unexpected error occurred";
    }
    
    // Send JSON response
    http_response_code($statusCode);
    header('Content-Type: application/json');
    echo json_encode([
        'status' => 'error',
        'message' => $message,
        'code' => $statusCode
    ]);
    
    exit;
}
