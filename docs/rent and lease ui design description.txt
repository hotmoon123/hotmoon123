## 🗄️ 3. PYTHON + SQL INTEGRATION BLUEPRINT

### 🐍 Python (Flask Example)
```python
# app.py
from flask import Flask, render_template, request, jsonify
from flask_jwt_extended import JWTManager, create_access_token, jwt_required
import sqlite3

app = Flask(__name__)
app.config['JWT_SECRET_KEY'] = 'your-secret'
jwt = JWTManager(app)

@app.route('/api/login', methods=['POST'])
def login():
    data = request.json
    user = query_db("SELECT role, id FROM users WHERE email=? AND password_hash=?", 
                    (data['email'], hash_password(data['password'])))
    if not user: return jsonify({'error': 'Invalid credentials'}), 401
    token = create_access_token(identity={'id': user['id'], 'role': user['role']})
    return jsonify({'token': token, 'redirect': f"/dashboard/{user['role']}"})

@app.route('/dashboard/landlord')
@jwt_required()
def landlord_dashboard():
    return render_template('landlord-dashboard.html')
```

### 🗃️ SQL Schema (SQLite/PostgreSQL)
```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  role TEXT CHECK(role IN ('landlord','tenant')) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE properties (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  landlord_id INTEGER REFERENCES users(id),
  address TEXT NOT NULL,
  unit_number TEXT,
  base_rent DECIMAL(10,2),
  status TEXT DEFAULT 'Vacant' CHECK(status IN ('Leased','Vacant'))
);

CREATE TABLE leases (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  property_id INTEGER REFERENCES properties(id),
  tenant_id INTEGER REFERENCES users(id),
  start_date DATE,
  end_date DATE,
  monthly_rent DECIMAL(10,2),
  status TEXT DEFAULT 'Active'
);
```

### 🔌 WebSocket & Cron Integration Points
- **Chat**: Use `Flask-SocketIO` or `FastAPI` WebSockets. Frontend: `const socket = io();`
- **Cron Toggles**: Store in DB `cron_jobs` table. Python `apscheduler` reads toggle state hourly.
- **IDOR Protection**: Middleware checks `request.user.role` + `WHERE landlord_id = ?` on every query.
